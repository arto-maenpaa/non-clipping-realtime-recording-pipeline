# Verified Setup: Rode Procaster, 2x Fast Track USB, iRig 2, Xiaomi Redmi

## Hardware Chain
- **Input Source:** Rode Procaster. I have removed the internal foam filter.
- **Pre-Amp / Interface:** M-Audio Fast Track USB into a second Fast Track USB via an AES 110-ohm cable. The second unit is set to accept a line-level signal to skip its mic preamp.
- **Impedance Bridge:** iRig 2
- **Mobile Hardware / Motherboard Receiver:** Xiaomi Redmi

## Knobs & Gain Staging
- **Bridge Setting:** 100%
- **Pre-Amp Drive Level:** All knobs about 75%

## Software Intake App
- **Recording App:** HedgeCam 2
- **API Flag Used:** Unprocessed (raw) API Hook

## Sonic Character
- Sounds relatively clean. Just I don't like the sound of the Procaster in general. I haven't run the Procaster into my PC so I can't compare how different it would sound.
